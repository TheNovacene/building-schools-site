# building-schools-site

Static site for [buildingschoolsinthecloud.com](https://buildingschoolsinthecloud.com) — part of The Novacene family of sites, served via GitHub Pages behind Cloudflare.

- `index.html` — single-page home
- `blog/` — static blog (23 posts rescued from the previous GoDaddy site)
- `style.css` — shared Novacene design language (schools-blue accent)
- `CNAME` — custom domain for GitHub Pages
